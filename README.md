# English to Urdu Translator 🇬🇧 → 🇵🇰

An AI-powered English to Urdu translation application built using:

- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- Helsinki-NLP OPUS-MT

## Features

- English to Urdu translation
- Simple web interface
- AI-powered translation
- Multiple sentence support
- Runs on Streamlit Community Cloud

## Model

Helsinki-NLP/opus-mt-en-ur
